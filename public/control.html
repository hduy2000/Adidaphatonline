🔴 Kết nối livestream TikTok

Đang kết nối tới server...
📖 Username lấy ở đâu? Lỗi kết nối phải làm sao?
1. Username là gì? Là tên tài khoản TikTok của người đang phát trực tiếp (đang LIVE). Mở app TikTok → vào hồ sơ người đó → dòng @username dưới tên. Lưu ý: người đó phải đang lên sóng thì tool mới kết nối được.

2. Nếu báo lỗi (signature/sign bị chặn):
  1. Lỗi "requires a Business plan" (Euler Stream): thường là quá tải tạm thời của gói free — tool đã tự thử lại 3 lần. Nếu vẫn lỗi: vào eulerstream.com → Sign up tài khoản miễn phí → Dashboard → API Keys → Create API key → copy key (dạng ei_key...) → dán vào ô Euler API Key bên dưới → Lưu cài đặt → kết nối lại. Key free đủ dùng cho 1 livestream.
  2. Hoặc: mở tiktok.com trên máy tính, đăng nhập, F12 → Application → Cookies → https://www.tiktok.com → copy cookie sessionid → dán vào ô Sessionid bên dưới → Lưu. (Cookie tt-target-idc đi kèm nếu có thì sửa trong config.json)
3. Nếu báo "KHÔNG đang phát trực tiếp": người đó chưa lên sóng — chờ họ mở live rồi bấm Kết nối lại.

🖥️ Lên sóng TikTok qua OBS

  1. Trong OBS Studio thêm nguồn Browser: URL http://localhost:3000/, kích thước 1080 × 1920 (dọc 9:16)
  2. Nhập username ở trên → bấm Kết nối livestream
  3. Bấm Start Streaming, chọn dịch vụ TikTok Live (hoặc dùng TikTok Live Studio)
Cấu hình cũng lưu vào file config.json — giữ nguyên sau khi khởi động lại.
